# 地方競馬 全券種・穴馬順位ポートフォリオ検証

Version: v2026.07.26.1
検証日: 2026-07-26

## 検証設計

中央と同じ手順で、地方の改善穴馬順位を全券種へ適用した。

- 対象: 単勝10倍以上の穴馬順位1～3位
- 券種: 単勝、複勝、馬連、ワイド、三連複、三連単1着・2着・3着固定
- 条件軸: 穴馬順位、オッズ帯、穴馬複勝確率、本命勝率、頭数
- 条件数: 8券種合計4,320パターン
- 固定検証: 2024年だけでルール選択、2025・2026年は未使用期間
- 頑健性: 最大払戻1件除外、既存穴馬順位との対照
- 単勝・複勝: `runs.tan_payout` / `runs.place_payout`
- 組合せ券: `payouts` テーブル

## 3期間を同時に探索した参考候補

全4,320パターンを事後的に3期間同時評価すると、3年すべて100%を超えた条件は1件だけだった。

- 券種: 三連単・穴馬順位1位の1着固定
- 穴馬単勝オッズ: 20～80倍
- 穴馬複勝確率: 16%以上
- 既存勝率1位: 35%以上
- 10頭以上
- ROI: 2024年101.0%、2025年125.6%、2026年185.1%

最大払戻の寄与率は2024年33.6%、2025年21.9%、2026年47.0%。最大払戻1件を除くと3期間すべて100%を維持できない。全期間を見てから選んだ事後条件でもあるため、確定ルールには数えない。

厳格条件「3期間100%以上、必要件数、最大払戻寄与20%以下」を満たすルールは0件だった。

## 改善順位と既存順位の対照

2025年の既存順位ROIは、単勝79.4%、複勝74.1%、馬連78.8%、ワイド69.6%、三連複74.0%、三連単1着65.7%、2着63.8%、3着64.6%だった。

拡張特徴後の三連単1着固定は113.3%まで改善しており、穴馬順位の改善効果は大きい。ただし他券種では控除率を突破できず、2026年には三連単1着固定も低下した。

## 最終判断

- 地方穴馬順位への拡張能力特徴追加は採用候補。
- 単勝、複勝、馬連、ワイド、三連複、三連単2着・3着固定は現条件では不採用。
- 三連単1着固定はC判定の検証通知に限定し、実績監視を継続。
- 現時点で「地方で安定して回収率100%を超える」と確定できる券種・条件はない。
- 次段階は2026年の低下を、会場、距離、馬場、頭数、前半レースの馬場傾向で事前分離できるか検証する。
